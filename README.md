## 项目简介

一个可以握在手里、装进透明管中的"电子海洋"：

- **灯板**：8 × 32 = 256 颗 1010 封装 WS2812 雾面灯珠组成的点阵屏
- **主控板**：ESP32-S3-FH4R2（无外挂 Flash）+ MPU-6050 六轴传感器
- **交互**：倾斜瓶子，重力方向实时改变水流方向；触摸铜箔唤醒，15 秒无操作休眠
- **联网**：Wi-Fi 配网后自动同步时间，水位随涨落潮时间变化
- **供电**：601235 / 300 mAh 锂电池，管线内嵌入式安装
- **外壳**：长 100 mm、外径 19 mm / 内径 18 mm 的 PC 透明管

## 复刻要点

1. **核心库版本**：ESP32 Arduino 核心使用 3.x.x（作者使用 3.0.2），2.x 与 3.x 差异较大，不要混用。
2. **灯珠驱动**：使用 FastLED 库；灯板建议走嘉立创 SMT 或代贴片，手贴 256 颗 1010 灯珠极易失败。
3. **主控焊接顺序**：先焊 ESP32 与 MPU-6050 两颗 QFN，确认无虚焊/连锡后再贴其它元件。
4. **R6 禁止焊接**：该 0 Ω 电阻仅用于引出复位脚调试，焊上会导致无法正常工作。
5. **触摸灵敏度**：调整 C22（2~50 pF，越小越灵敏），实测不建议低于 25 pF。
6. **主控选型**：必须为 ESP32-S3-FH4R2（内置 Flash），误买 S3-R8 等无内置 Flash 型号将无法烧录。
7. **可自定义项**：`water_sim.cpp` 第 40 行附近可切换调色板（0~2）；第 25 行附近可改最高/最低潮水位；`time_sync.cpp` 第 13 行附近可改不同时间对应的水位。
8. **操作方式**：轻触铜箔唤醒；熄屏状态下快速点击 6 次进入配网模式，手机连接提示热点后自动跳转配网页。
